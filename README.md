# TA:Escalation — Справочник ARM

**[>>> Открыть справочник <<<](https://igetpaid.github.io/totala-guide/)**

Справочное PWA-приложение по юнитам и постройкам фракции **ARM** из мода [Total Annihilation: Escalation](https://taesc.tauniverse.com/).

## Возможности

- 156 юнитов ARM (T1–T4) с подробными описаниями на русском
- 220 оригинальных иконок юнитов
- Постройки: оборонительные сооружения и экономика
- Советы по стратегии
- FAQ (автосбор деревьев, Guard, Adjacency Bonus и др.)
- Расшифровка терминов (AA, EMP, LRPC, VTOL и др.)
- Работает оффлайн (PWA)
- Тёмная тема в стиле игры

## Как пользоваться

1. Откройте [ссылку](https://igetpaid.github.io/totala-guide/) на телефоне или ПК
2. Выберите раздел: Юниты или Постройки
3. Переключайте тиры (T1/T2/T3/T4)
4. Нажмите на юнита — увидите подробную карточку

## Технологии

- HTML + CSS + JavaScript (vanilla)
- PWA (Service Worker + Manifest)
- GitHub Pages
